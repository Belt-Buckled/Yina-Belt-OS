## No-drift rule

Every logo placement embeds a pixel-exact alpha extraction from the approved Drive reference. Never retype, redraw, trace, stretch, skew, condense, expand, restack, or substitute fonts. Approved palette recoloring is allowed only when the underlying alpha silhouette and aspect ratio remain unchanged.

The extracted PNG masters are an interim production authority, not a substitute for an original designer vector. When an original vector is received, compare it directly with the Drive reference before replacing these masters.

## Vendor controls

Confirm final dielines with the selected vendor. Require physical proofs for color, foil, woven labels, embroidery and small-scale reproduction. Replace all bracketed placeholders and confirm textile/legal copy before manufacturing.
